📖 Buku Panduan

— Catatan Pemain —

🖱 Kontrol Mouse (Komputer)

  • Tahan klik kanan lalu geser mouse untuk memutar arah bidikan. Kursor akan terkunci di tempat selama tombol ditahan.
  • Tahan/klik klik kiri untuk menembak (senjata full-auto akan menembak beruntun selama ditahan).
  • Tekan tombol 1 / 2 / 3 untuk ganti senjata: Pistol, Sniper, SMG.
  • Tahan tombol Spasi atau W untuk mengintip lewat scope sniper.
  • Tekan tombol V untuk memainkan animasi inspeksi senjata yang sedang dipegang — jumlah amunisi di magasin akan terlihat jelas di layar digital pada senjata.
  • Tekan tombol R untuk mengisi ulang (reload) amunisi kapan saja.

👆 Kontrol Sentuh (HP/Tablet)

  • Geser jari di layar untuk membidik.
  • Ketuk atau tahan tombol TEMBAK untuk menembak.
  • Tahan tombol SCOPE untuk mengintip lewat sniper.
  • Ketuk tombol INSPEKSI untuk memutar/menampilkan senjata yang sedang dipegang, sekaligus melihat sisa amunisinya.
  • Ketuk tombol RELOAD kapan saja untuk mengisi ulang amunisi secara manual.
  • Senjata akan otomatis reload saat amunisi habis — cukup tunggu sebentar sebelum menembak lagi.
  • Gunakan tombol ATUR TOMBOL untuk memindah/mengubah ukuran tombol di layar.

⚙ Pengaturan

  • Buka KONTROL & SENSITIVITAS untuk mengatur seberapa cepat arah bidikan bergeser (1–120), atau mengaktifkan mode Gyroscope.

🎯 Mode Permainan

  • MODE WAKTU: 60 detik untuk mendapat skor setinggi mungkin.
  • MODE BEBAS: bermain tanpa batas waktu, tekan SELESAI kapan saja untuk melihat hasil.

🔫 Amunisi & Reload

  • Setiap senjata punya kapasitas magasin sendiri: Pistol 12, Sniper 10, SMG 60 peluru.
  • Sisa amunisi terlihat di HUD atas dan pada layar digital kecil di badan senjata (terlihat jelas saat inspeksi).
  • Reload otomatis berjalan saat magasin kosong; tekan R (PC) untuk reload manual kapan saja.

💯 Skor & Statistik

  • Tembakan ke kepala (headshot) memberi bonus skor lebih besar.
  • Jaga streak (tembakan beruntun tanpa meleset) untuk mengejar rekor tertinggi.

🖱 Kontrol & Sensitivitas

Pilih cara membidik: geser layar/mouse (non-gyro, bawaan) atau miringkan perangkat (gyro).
